# ms.net_lab_work_tour_manager
# Первичные требования
- веб-приложение / Web API
- есть группы, площадки, заявки на концерты, концерты, избранное
- менеджеры групп и площадок договариваются через заявки
- концерт создаётся только после подтверждения заявки
- зрители смотрят концерты, цены билетов, добавляют в избранное
- админ управляет пользователями, ролями, популярностью групп
 
# Минимальные требования

Анонимный посетитель

- открыть в браузере/скачать приложение
- без регистрации просмотреть список концертов (прошедшие и предстоящие)
- посмотреть цены билетов
- поиск/фильтрация по городу / дате / группе / жанру / статусу
- просмотреть карточку концерта (группа, площадка, дата, цена, описание)
- просмотреть список групп (жанр, описание)
- просмотреть список площадок (город, адрес, вместимость)
- при желании зарегистрироваться
  
Зарегистрированный пользователь

- всё, что доступно анониму
- зарегистрироваться / войти по email и паролю
- редактировать свой профиль
- добавить концерт в избранное
- добавить группу в избранное
- посмотреть список избранного (в т.ч. отменённые концерты)
- удалить из избранного
- получить уведомление (внутри приложения при входе в него) об отмене концерта из избранного
  
Менеджер группы

- зарегистрироваться / войти
- создать группу
- изменить уровень популярности группы?
- редактировать свою группу (название, жанр, описание)
- управляет приемом заявок (может их закрыть)
- смотреть входящие запросы от площадок
- подтвердить / отклонить запрос
- создать запрос
- посмотреть список своих концертов во всех статусах
- опубликовать концерт
- отменить концерт (с указанием причины)
- отметить концерт как завершённый
- смотреть статистику по своим концертам
- весь функционал обычного пользователя
  
Менеджер площадки

- зарегистрироваться / войти
- создать площадку
- редактировать свою площадку (название, город, адрес, вместимость)
- смотреть популярные группы
-  отправить запрос на концерт популярной группе (только ели группа принимает заявки)
- смотреть входящие запросы от групп
- подтвердить / отклонить запрос
- посмотреть концерты на своей площадке
- отменить концерт (с указанием причины)
- смотреть статистику по своей площадке
- весь функционал обычного пользователя

Администратор

- войти в ЛК
- посмотреть список пользователей
- сменить роль пользователя
- заблокировать / удалить пользователя
- перепривязать группу к другому менеджеру
- изменить уровень популярности группы
- перепривязать площадку к другому менеджеру
- посмотреть все заявки и концерты
- управлять любыми сущностями
- весь функционал обычного пользователя

# Технические требования

- в системе существуют 5 ролей — аноним, пользователь, менеджер группы, менеджер площадки, администратор
- аноним— не хранится в БД
- возможность авторизации, регистрации
- концерт создаётся только через подтверждённую заявку
-сохранять концерты в избранное могут только зарегестрированные пользователи

Правило приглашения от площадки:

Менеджер площадки может создать заявку только группе, у которой высокий уровень популярности и открыт прием заявок

Правило видимости:

 Отмененные концерты не видны в общем списке, но если они находятся у пользователя в избранном, то ему они остаются видны в списке избранных
 
Правило создания концерта:

 концерт создаётся только при принятой заявке (с каждой из сторон)
 
Правило отмены:

 Отменить можно запланированные концерты и уже опублкованные, завершенные отменить нельзя. При отмене создаются уведомления всем, у кого концерт в избранном
